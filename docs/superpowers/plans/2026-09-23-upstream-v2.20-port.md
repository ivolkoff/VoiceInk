Источник: `upstream/main` на `d7b528aa` (2026-09-22). Разбор и решения — `docs/upstream-scout.md`.
Дерево v2.20 для чтения: `git show upstream/main:<path>` (апстрим живёт на новой раскладке
`VoiceInk/Features/...`, `VoiceInk/Infrastructure/...` — портируем руками по содержимому, не cherry-pick).

## Ограничения

- Раскладка форка не меняется: новые файлы кладём в существующие папки форка (`Services/`, `Views/`,
  `Shortcuts/`, `Transcription/`, `Paste/`).
- Не затереть обратные пробелы (список в `docs/upstream-scout.md`): переключатель раскладки
  (`convertLayout`, `KeystrokeTap.flushMarker` в `ShortcutMonitor`), ru-локализация, re-transcribe по
  раскладке, paste in chunks, emotion annotation.
- Новые UI-строки получают ru-перевод в `Localizable.xcstrings` (пункт L1, одним проходом в конце).
- Логика с ветвлениями оставляет один тест в `VoiceInkTests/` (swift-testing).
- Коммит на каждый закрытый пункт, conventional commits, без AI-атрибуции.

Сборка и тесты — как в `docs/superpowers/plans/2026-09-17-layout-switcher.md` (ad-hoc подпись,
`-only-testing`, `RetranscribeInPlaceTests` известно красный — не запускать).
