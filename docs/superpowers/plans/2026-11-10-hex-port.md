# Hex Port (Return to App, Release Tail, Silence Gate) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port three dictation behaviours from anomalyco/hex into the fork: paste goes back to the app where recording started, recording keeps a short tail after the stop press, and silent captures skip the model.

**Architecture:** Each behaviour is a pure policy type with Swift Testing tests plus a thin wiring change in the existing recorder pipeline (`VoiceInkEngine` → `TranscriptionPipeline` → `CursorPaster`). No new dependencies, no change to the recorder hardware path.

**Tech Stack:** Swift 5, AppKit, Core Audio meter already in `CoreAudioRecorder`, Swift Testing (`import Testing`).

**Spec:** `docs/upstream-scout-hex.md` (findings #1–#3). Hex reference code: `src/paste/return_to_app.rs`, `src/dictation.rs` (`POST_RELEASE_TAIL`, `loudest_window_dbfs`) at `anomalyco/hex@3e69978`.

## Global Constraints

- App target macOS 14.4; no `@available(macOS 15, *)` on types.
- Recorded files are 16 kHz mono PCM16 WAV with a 44-byte header (`CoreAudioRecorder.swift:404-411`).
- File-system-synchronized groups: new `.swift` files need no pbxproj edit.
- New UI strings get Russian translations in `VoiceInk/Resources/Localizable.xcstrings` (`"ru": {"stringUnit": {"state": "translated", "value": …}}`).
- Never run the whole `VoiceInkTests` target (`RetranscribeInPlaceTests` crashes, known). Run one suite:
  `xcodebuild test -project VoiceInk.xcodeproj -scheme VoiceInk -destination 'platform=macOS' -xcconfig LocalBuild.xcconfig CODE_SIGN_IDENTITY=- CODE_SIGNING_REQUIRED=NO DEVELOPMENT_TEAM="" CODE_SIGN_ENTITLEMENTS="$PWD/VoiceInk/VoiceInk.local.entitlements" -only-testing:VoiceInkTests/<Suite> 2>&1 | tail -30`
  (not yet run in this form: if Task 1 Step 2 fails for a build-setting reason, fix the flags here once).
- Work on branch `feat/hex-port`. Conventional commits, no AI attribution, no push.
- Comments only for a non-obvious *why*, ≤ 3 lines; no `shortcut:`/`ponytail:` markers.

## Review Focus

- **Target app quit during dictation** → no paste into a random app; warning says the text is in history: `ReturnToApp.decision` returns `.cannotReturn` (Task 1 test `terminatedTargetCannotReturn`).
- **Recording started while a VoiceInk window was frontmost** → plain paste, no self-activation: `.paste` for own pid (Task 1 test `ownAppPastesInPlace`).
- **A key click or the stop press itself right after release** → tail does not grow past 200 ms (Task 2 test `keyClickDoesNotExtend`).
- **Esc during the tail** → the tail ends at once and the cancel path runs (Task 2 Step 6, manual).
- **Header-only, truncated or odd-length WAV** → no crash; treated as silent (Task 3 tests `headerOnlyIsSilent`, `oddByteCountDoesNotCrash`).

```bash
import sys,os,struct,math
d=sys.argv[1]; fs=sorted((os.path.join(d,f) for f in os.listdir(d) if f.endswith('.wav')),key=os.path.getmtime)[-10:]
def db(w):
```

```swift
var speech = 0, gap = 0
for flag in window.reversed() {
    if flag { speech += 1; gap = 0; if speech >= speechFrames { return true } }
    else { gap += 1; if gap > speechGapFrames { return false } }
}
return false
```

### Task 3: Silence gate

**Files:**
- Create: `VoiceInk/Transcription/Processing/AudioSilenceGate.swift`
- Modify: `VoiceInk/Transcription/Engine/TranscriptionPipeline.swift:99-104`, `VoiceInk/Resources/Localizable.xcstrings`
- Test: `VoiceInkTests/AudioSilenceGateTests.swift`

**Interfaces:**
- Produces:
  - `enum AudioSilenceGate`
  - `static let thresholdDBFS: Float = -50`, `static let windowSamples = 480` (30 ms at 16 kHz)
  - `static func loudestWindowDBFS(pcm16WAV data: Data) -> Float` — DC-removed RMS of each 480-sample window after the 44-byte header, loudest one, `20·log10(max(rms, 1e-6))`; no full window → `-120`
  - `static func isSilent(audioURL: URL) -> Bool` — unreadable file → `false` (the model decides)
  - nested `enum NoSpeechError: LocalizedError { case noSpeech }` (used as `AudioSilenceGate.NoSpeechError.noSpeech`), `errorDescription` = `String(localized: "No speech detected")`

- [ ] **Step 1: Write the failing test** `VoiceInkTests/AudioSilenceGateTests.swift`, `struct AudioSilenceGateTests`, with helper `wav(_ samples: [Float]) -> Data` = 44 zero bytes + each sample as `Int16(sample * 32767)` little-endian:

```swift

    // 0.1-amplitude 1 kHz sine is -23 dBFS RMS
    var samples = [Float](repeating: 0, count: 16_000)

    #expect(abs(AudioSilenceGate.loudestWindowDBFS(pcm16WAV: wav(samples)) - -23) < 0.5)
}
@Test func whisperLevelIsNotSilent() {

}
@Test func headerOnlyIsSilent() {
    #expect(AudioSilenceGate.loudestWindowDBFS(pcm16WAV: Data(count: 44)) == -120)
}
@Test func oddByteCountDoesNotCrash() {

    data.append(0x7F)
```
