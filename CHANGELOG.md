# Changelog

Версия совпадает с `MARKETING_VERSION` приложения. Новая возможность поднимает minor, исправление — patch.

## [1.81.0] - 2026-10-03

### Added
- Модель Parakeet Ultra (Parakeet V3, дообученная Moondream, 640 МБ): те же 25 языков и скорость, ниже ошибка на всех языках FLEURS, на русском −1,3 п.п. WER. Стоит первой в рекомендуемых; Parakeet V3 остаётся в списке запасной. FluidAudio обновлён до `762baf67`.

### Fixed
- Если AI-улучшение упало, ↵ в Quick History, «скопировать последнюю транскрипцию», «вставить последнее улучшение» и копирование после повторной транскрипции отдают исходный текст, а не строку «Enhancement failed: …».

## [1.80.21] - 2026-09-29

### Fixed
- Восстановление буфера обмена после вставки ждёт, пока целевое приложение прочитает вставку (не дольше 5 с сверх задержки): медленное приложение больше не вставляет восстановленный старый буфер вместо диктовки.
- Автоочистка аудио сначала сохраняет отвязку записей и только потом удаляет файлы: сбой сохранения не оставляет записи со ссылками на удалённое аудио; неудалившийся файл привязывается обратно.
- Неудачное сохранение правки замены в словаре откатывает изменение в памяти, а не оставляет его действующим после «Отмена».
- Пагинация истории не пропускает записи с одинаковым временем на границе страницы.
- Алерт импорта бэкапа перечисляет только категории, данные которых есть в файле, и сообщает, если импортировать нечего.

## [1.80.20] - 2026-09-29

Ранее сохранённый выбор откатывается на Gemini, а конфигурация Power Mode со старым выбором его не применяет.

## [1.80.18] - 2026-09-29

## [1.80.16] - 2026-09-29

### Fixed
- Провал переключения микрофона посреди записи (выдернутый микрофон) больше не оставляет приложение в состоянии «идёт запись» над мёртвым захватом: сессия корректно отменяется, частичная запись сохраняется в историю как отменённая, панель рекордера закрывается.
- Буферы аудиозахвата выравниваются под реальный размер IO-цикла устройства (DAW/драйверы могут ставить >4096 кадров): раньше каждый колбэк молча отбрасывался — запись шла, файл выходил пустым. Теперь подборка буферов по устройству (старт и переключение) и одна запись в лог при переполнении.

## [1.80.15] - 2026-09-29

### Fixed
- Настройки: импорт бэкапа с включёнными Power Mode включает флаг UI (иначе импортированные хоткеи мертвы, а раздел скрыт); удаление второго шортката посреди записи больше не «воскрешает» отвязанную комбинацию; «Run Cleanup Now» честно показывает число удалённых записей или провал вместо всегда-«готово»; список приоритетных устройств остаётся редактируемым при отключённых устройствах.
- Редактор Power Mode: закрытие без сохранения возвращает исходный хоткей (новая запись применялась мгновенно и пережимала отмену); возврат модели мульти↔английский не переписывает язык навсегда; пикер AI-модели показывает дефолт своего провайдера, а не глобальную модель чужого; удаление выбранного эмодзи сбрасывает выбор; пустая полоса деталей под конфигами без чипов убрана.
- Auto Learn: битый файл предложений больше не стирает все предложения при следующем сохранении (бэкап + почастевой декод, провал загрузки ретраится); провал записи очереди при освобождении батча не оставляет его навечно в «reviewing» без ретрая.
- Быстрая панель словаря: строки локализованы (русские литералы показывались в английской локали).

## [1.80.13] - 2026-09-29

### Fixed
- Транскрипция файлов и повтор последней записи: записи больше не застревают в статусе «pending» (из-за чего автоочистка их никогда не трогала и они копились вечно), повтор по хоткею не гоняется с живой записью (гейт + собственный реестр сервисов), провал сохранения откатывает запись и WAV вместо молчаливого «успеха», осиротевшие WAV удаляются при отмене/ошибке очереди.
- Вставка: две вставки больше не перемешивают чанки в одно поле (сессии выстроены в очередь), защищённое поле ввода (пароль) отклоняет вставку с видимым уведомлением вместо тихого «прошло мимо», провал подготовки клипборда больше не лишает пользователя его исходного буфера обмена.
- Облачные модели: имена моделей AssemblyAI приведены к таблице клиента (стриминг и батч снова работают; существующий выбор модели придётся пере-выбрать один раз), Deepgram получает пользовательский словарь (keyterm), разоязычный whisper-промпт больше не отправляется в облачные и кастомные запросы (порча вывода), streaming-only провайдер (Cartesia) даёт внятную ошибку вместо «провайдер не поддерживается», нечитаемый список кастомных моделей сохраняется в бэкап-ключ вместо перманентного стирания.

## [1.80] - 2026-09-24

### Added
- Правка выделенного голосом. Если при старте записи в редактируемом поле выделен текст, AI решает, что надиктовано. Инструкцию («переведи на английский», «сделай списком») он применяет к выделенному, обычный текст возвращает как есть, и результат заменяет выделение. Если к моменту вставки выделение изменилось, результат копируется в буфер обмена. Вопрос о выделенном тексте («во сколько созвон?») выделение не меняет: ответ показывается в уведомлении и кладётся в буфер обмена. Выделение больше лимита символов не трогается: надиктованный текст уходит в буфер обмена с уведомлением. В приложениях, которые не отдают выделение через Accessibility (часть Electron) или оставляют элемент нередактируемым (веб-страница, PDF, вывод терминала), остаётся обычная диктовка. Выключатель «Edit selection by voice» лежит в настройках улучшения, по умолчанию включён и сохраняется в бэкапе.
- Автообучение словаря (Auto Learn из апстрима v2.20). После вставки VoiceInk до 60 секунд следит за полем через Accessibility. Правки пользователя становятся кандидатами «было → стало», их проверяет выбранный AI-провайдер, и результат попадает в словарь: сразу с отменой или через панель ручной проверки. Настройки лежат в панели словаря и сохраняются в бэкап.
- Импорт и экспорт словаря в JSON `voiceink.dictionary` v1. Перед импортом показывается предпросмотр с дублями, конфликтами и циклами; есть режимы объединения и замены. Старый формат экспорта форка по-прежнему читается.
- Quick History: плавающая панель с поиском по последним транскрипциям. Return вставляет выбранную транскрипцию в текущее приложение. Панель открывается глобальным сочетанием клавиш или из меню-бара.
- Режим записи «Double Tap»: запись включается и выключается двойным нажатием модификатора.
- Отмена загрузки моделей Whisper и FluidAudio с удалением недокачанных файлов.
- Русский перевод новых строк и строк, которые раньше оставались без перевода.

### Changed
- Пока экран заблокирован, глобальные сочетания клавиш не срабатывают.
- Стриминг Parakeet: смена знака конца предложения больше не подтверждает и не сбрасывает устойчивые слова.

### Fixed
- Триггер раскладки на одиночном модификаторе (Right Option) больше не срабатывает при отпускании после сочетания вроде ⌥⇧-.
- Переключатель раскладки: замена слова выполняется атомарно и не перемешивается с клавишами, которые пользователь нажимает во время замены. Нет автоконвертации, когда фокус стоит в списке или таблице. Мёртвые клавиши больше не путают буфер.
- Правила замены, меняющие только регистр (github → GitHub), больше не отбрасываются при импорте как цикл.
- Двойное нажатие сочетания Power Mode больше не сбрасывается монитором сочетаний записи.
- Quick History не перехватывает Return, стрелки и Escape, пока метод ввода (китайский, японский) набирает текст.
- Кнопка загрузки сразу после отмены теперь дожидается отменённой загрузки и запускает новую, а не молчит.
- Auto Learn:
  - ревью идёт только через провайдер, выбранный в словаре, или через провайдер улучшения; провайдеру, чей ключ сохранён только для транскрипции, текст больше не уходит;
  - Ollama распознаётся как подключённая сразу после запуска;
  - у провайдера Custom берётся текущая модель;
  - таймаут ревью — не меньше 30 секунд;
  - замена текста при повторной транскрибации и при улучшении выделенного текста больше не засчитывается как правка пользователя.
